Put YOUR OWN Donkey Kong Country ROM in this folder, named exactly:

  dkc1.sfc

This project does NOT provide any ROM, BIOS, game code or game data, and
never will. Do not ask for one. Use a copy dumped from a cartridge you own.

Requirements:
  Game ...... Donkey Kong Country (USA) v1.0
  Header .... none (headerless)
  Size ...... 4194304 bytes
  SHA-256 ... fa8cacf5bbfc39ee6bbaa557adf89133d60d42f6cf9e1db30d5a36a469f74d15

Check it:
  python tools\cart2p\verificar_rom.py

If your file has a 512-byte copier header (.smc), drop it here with any
.smc name and the checker writes a clean dkc1.sfc next to it (your file is
never changed). v1.1, v1.2, Europe and Japan are rejected: the mod is made
for USA v1.0 only, and the checker tells you which version you have.

The SHA-256 is checked three times: at build time (verificar_rom.py and
scripts\generate_snesrecomp.py), when preparing the mod files
(preparar_desde_rom.py) and when the game starts (runner\verified_rom.c).

ROM files are git-ignored. Never commit, upload or share them.
