NO ROMS, NO PIRACY
------------------
The authors of Cart Chase 2P do not provide, host, link to or distribute
any ROM, BIOS, copyrighted game code, graphics, music or any other
copyrighted material, and do not condone piracy. Requests for ROMs will be
ignored. Cart Chase 2P is only a mod: source code that works on top of one
specific version of the game, Donkey Kong Country (USA) v1.0, which each
user must supply from their own legally obtained copy. The build refuses
any other file (SHA-256 check).


WHAT THIS PROJECT DOES NOT CONTAIN
----------------------------------
No ROM, no game code, no graphics, no level maps, no music, no save
states and no other data copied from the game. Everything the mod needs
from the game is produced on YOUR computer from YOUR OWN legally obtained
copy of Donkey Kong Country (USA) v1.0:

  - the recompiled game code (scripts/generate_snesrecomp.py, at build time)
  - start states, rail profiles, world skins, compiled stages and editor
    images (tools/cart2p/preparar_desde_rom.py, once after building)

The stages of the mod are distributed only as RECIPES
(cart2p/etapas_fuente/*.json): column numbers, object positions and
options, i.e. instructions that refer to the user's ROM, not game data.
tools/cart2p/huellas_preparado.txt contains only SHA-256 fingerprints so
users can verify their locally produced files.

Release packages are produced with tools/cart2p/empaquetar_publico.py,
which uses an allow-list and refuses to build the package if any file
contains a 32-byte run identical to the ROM.
