CART CHASE 2P - STAGE RECIPES
=============================
Each <id>.json file in this folder is the editable SOURCE of one stage.
A recipe contains only column numbers, object positions and options: it
is a set of instructions applied to YOUR ROM, not game data.

The game does not read the recipes to play: it loads the compiled
cart2p\stages\<id>.c2p, which tools\cart2p\preparar_desde_rom.py builds
from your ROM (the in-game editor reads and writes the .json files).

  Edit in the game:     main menu -> "EDITOR" (saves and compiles)
  HTML editor:          cart2p\JUGAR.bat option 2
  Edit by hand:         change the .json, then JUGAR.bat option 4
  Full format:          cart2p\docs\FORMATO_ETAPAS.txt
  Stage list:           CATALOGO_ETAPAS.txt (generated by
                        tools\cart2p\compilar_etapas.py)
  Previous versions:    historial\<id>_<date>.json (left by the editor)

File names:
  e001-e050  Mine Cart Carnage (families REMIX, SPRINT, HOYOS (pits),
             TRANQUILA (calm), LARGA (long), MIXTA (mixed))
  e051-e100  Mine Cart Madness, same families
  e101-e140  Carnage with a THEME (another world behind the track):
             jungla (jungle), cueva (cave), fabrica (factory), nieve
             (snow), arboles (treetops), bosque (forest), templo (temple),
             mina (mine), 5 of each
  e141-e180  Madness with the same 8 themes (5 of each)
  remix*, inventada*, azar_*  hand-made and random stages
  others     made in the editor or with "ETAPAS AL AZAR" (random stages)

SEAMLESS STAGES
Every stage is a route through the original level that only jumps between
identical columns of scenery, so the joins are invisible. The CORTE (cut)
column of the stage list must be 0.

To recreate the generated batch from scratch (overwrites edits):
  python tools\cart2p\generar_etapas.py --reemplazar
Without --reemplazar it leaves existing recipes alone.
